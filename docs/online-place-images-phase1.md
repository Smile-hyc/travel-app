# 在线真实图片第一阶段：高德 POI 图片闭环

本阶段只接入高德 POI 返回的 `photos` 图片，目标是让探索页和地点详情页先具备“真实在线图片 → 安全降级占位”的完整闭环。

## 已实现范围

- FastAPI 在解析高德 POI 时，把 `photos` 转换为项目内部图片模型 `PlaceImage`。
- `PlaceSummary` 同时保留：
  - `images`：结构化图片列表；
  - `coverImageUrl`：首图地址；
  - `imageUrls`：兼容旧字段。
- Android 新增 Coil 图片加载能力。
- 探索页地点卡片优先展示真实封面图，失败时显示本地浅色占位。
- 地点详情页顶部展示真实封面图，内容区展示横向图片图集。
- 仅对白名单域名 `store.is.autonavi.com` 允许明文 HTTP 图片加载，不全局放开明文流量。

## 暂不实现

- 不接 Wikimedia、Unsplash、小红书等其他图片来源。
- 不抓取网页图片。
- 不编造图片版权、作者、评分或热度。
- 不做图片上传、收藏相册或本地缓存管理。

## 后续建议

1. 先稳定高德图片展示和失败占位。
2. 再增加 Wikimedia/开放授权图片作为补充来源。
3. 最后再考虑攻略平台或用户图片，并单独处理授权、来源标注和缓存策略。
